主讲改用“朋友陪我准备上台唱歌”真实案例。对照手写原稿、学生独立评阅与同份既有AI反馈，承认已有陪练和成功结果，聚焦可继续展开的关键帮助过程。撤下容易受OCR歧义影响的where/wall案例。教师追问与作者回应支架均标明教学示范，不冒充实际二稿或新增AI反馈。

包含两幅教学概念插画、原稿放大、可暂停及分步控制的流程动画，以及18秒720p案例回放动画。真实操作入口的 A 案例已与本页“上台唱歌”统一；B、C 保持原绑定。讲解页按钮直接进入 A 案例的题目与标准步骤。

方向键翻页；N讲稿；R重播；F全屏。设置中可调字体、动态效果和实操路线。尊重系统减少动态效果。正式操作与文献需要联网；另附的单文件离线版可独立查看正文、插图、原稿与动画。

网页文件为index.html、style.css、data.js、app.js和assets。数据仅含匿名公开教学材料，不含账号、授权或私有案例绑定。
